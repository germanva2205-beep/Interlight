# Help Me (H&M)

Голосовой помощник для Android на Flutter. Двойное нажатие громкости → слушает → показывает, как понял → «Подтвердить» → выполняет и закрывается.

## Сборка
APK собирает GitHub Actions (`.github/workflows/build.yml`): Actions → последний запуск → артефакт **HelpMe-apk**.
Папка `android/` генерируется в CI (`flutter create`), а нативные файлы берутся из `android_overlay/`.

## Первый запуск
1. Установи APK, разреши микрофон и уведомления.
2. Настройки телефона → Специальные возможности → Help Me → включить (нужно для двойного нажатия громкости).
